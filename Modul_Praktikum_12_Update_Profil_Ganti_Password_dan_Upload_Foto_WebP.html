A. Gambaran Besar: Dari Profil Baca-Saja ke Profil Interaktif & Ringan

Pada Modul 11 kemarin, kolom foto sudah kita siapkan di tabel users dalam keadaan nullable, dan tab Profil (src/app/(tabs)/profil.tsx) baru sebatas menampilkan nama, email, nomor HP, serta tombol Keluar dari Akun. Di Modul 12 ini, kita akan menghidupkan layar Profil yang sudah ada agar pengguna dapat:

  • Memperbarui Data Profil (Nama Lengkap, Alamat Email, dan Nomor HP) langsung ke database MySQL serta otomatis menyegarkan tampilan di AsyncStorage dan tab Beranda.
  • Mengganti Kata Sandi dengan verifikasi kata sandi lama (current_password) di sisi server demi keamanan akun.
  • Mengunggah Foto Profil secara langsung menggunakan Kamera HP maupun mengambil dari Galeri HP melalui expo-image-picker.
  • Keamanan & Performa Server-Side: Server Laravel 13 memvalidasi tipe MIME gambar secara ketat (hanya image/jpeg, image/png, image/webp) dengan batas ukuran maksimal 5 MB (5.120 KB), lalu otomatis meng-crop, mengubah ukuran (maks 512×512 px), dan mengonversinya menjadi WebP memakai ekstensi bawaan PHP GD. Hasilnya, foto kamera 4–5 MB menyusut menjadi sekitar 25–65 KB sehingga aplikasi React Native tidak pernah berat saat memuat avatar!

Langkah 2: Membuat Service Konversi & Kompresi WebP (app/Services/ProfilePhotoService.php)

Supaya controller tetap ramping dan rapi, kita pisahkan logika pengolahan gambar ke kelas layanan khusus. Buat folder baru Services di dalam app/, lalu buat file baru app/Services/ProfilePhotoService.php: 

<?php

namespace App\Services;

use App\Models\User;
use Illuminate\Http\UploadedFile;
use Illuminate\Support\Facades\Storage;
use RuntimeException;

class ProfilePhotoService
{
    /**
     * Validasi binary gambar, auto-rotate EXIF kamera, crop 1:1 maks 512x512 px,
     * konversi ke format WebP ringan, lalu hapus foto profil lama dari disk.
     */
    public function storeAndOptimize(UploadedFile $file, User $user): string
    {
        if (! extension_loaded('gd')) {
            throw new RuntimeException('Ekstensi PHP GD belum aktif di server.');
        }

        $rawBinary = file_get_contents($file->getRealPath());
        if ($rawBinary === false) {
            throw new RuntimeException('Gagal membaca file gambar yang diunggah.');
        }

        $sourceImage = @imagecreatefromstring($rawBinary);
        if ($sourceImage === false) {
            throw new RuntimeException('Isi file bukan gambar yang valid atau file rusak.');
        }

        // 1. Perbaiki rotasi otomatis foto portrait dari kamera HP (EXIF)
        $sourceImage = $this->fixExifOrientation($sourceImage, $file);

        $origWidth  = imagesx($sourceImage);
        $origHeight = imagesy($sourceImage);

        // 2. Center-crop persegi (1:1) & perkecil maksimal 512x512 px
        $cropSize   = min($origWidth, $origHeight);
        $srcX       = (int) floor(($origWidth - $cropSize) / 2);
        $srcY       = (int) floor(($origHeight - $cropSize) / 2);
        $targetSize = min($cropSize, 512);

        $canvas = imagecreatetruecolor($targetSize, $targetSize);
        imagealphablending($canvas, false);
        imagesavealpha($canvas, true);
        $transparent = imagecolorallocatealpha($canvas, 0, 0, 0, 127);
        imagefilledrectangle($canvas, 0, 0, $targetSize, $targetSize, $transparent);

        imagecopyresampled(
            $canvas,
            $sourceImage,
            0,
            0,
            $srcX,
            $srcY,
            $targetSize,
            $targetSize,
            $cropSize,
            $cropSize
        );

        // 3. Konversi & kompres ke format WebP (kualitas 80 -> ukuran sangat ringan)
        ob_start();
        if (function_exists('imagewebp')) {
            imagewebp($canvas, null, 80);
            $extension = 'webp';
        } else {
            imagejpeg($canvas, null, 82);
            $extension = 'jpg';
        }
        $optimizedBinary = ob_get_clean();

        unset($sourceImage, $canvas);

        if ($optimizedBinary === false || $optimizedBinary === '') {
            throw new RuntimeException('Gagal mengonversi foto profil di server.');
        }

        // 4. Simpan ke storage/app/public/profiles/
        $relativePath = sprintf('profiles/user_%d_%d.%s', $user->id, time(), $extension);
        Storage::disk('public')->put($relativePath, $optimizedBinary);

        // 5. Hapus foto profil lama jika ada agar ruang server tetap bersih
        if (! empty($user->foto) && Storage::disk('public')->exists($user->foto)) {
            Storage::disk('public')->delete($user->foto);
        }

        return $relativePath;
    }

    private function fixExifOrientation(\GdImage $image, UploadedFile $file): \GdImage
    {
        if (! function_exists('exif_read_data')) {
            return $image;
        }

        $mime = strtolower((string) $file->getMimeType());
        if (! in_array($mime, ['image/jpeg', 'image/jpg'], true)) {
            return $image;
        }

        $exif = @exif_read_data($file->getRealPath());
        $orientation = $exif['Orientation'] ?? 1;

        return match ($orientation) {
            3 => imagerotate($image, 180, 0) ?: $image,
            6 => imagerotate($image, -90, 0) ?: $image,
            8 => imagerotate($image, 90, 0) ?: $image,
            default => $image,
        };
    }
}

Langkah 3: Membuat ProfileController (app/Http/Controllers/Api/ProfileController.php)

Buat controller baru khusus pengelolaan profil melalui terminal di folder NovinaldiAppApi: 

php artisan make:controller Api/ProfileController

Buka file app/Http/Controllers/Api/ProfileController.php dan isi dengan tiga fungsi utama: updateProfile, updatePassword, dan updatePhoto (beserta validasi MIME ketat & maksimal 5 MB): 

<?php

namespace App\Http\Controllers\Api;

use App\Http\Controllers\Controller;
use App\Services\ProfilePhotoService;
use Illuminate\Http\Request;
use Illuminate\Support\Facades\Hash;
use Illuminate\Validation\Rule;
use Throwable;

class ProfileController extends Controller
{
    public function __construct(private ProfilePhotoService $photoService)
    {
    }

    // 1. Update Nama, Email, dan Nomor HP
    public function updateProfile(Request $request)
    {
        $user = $request->user();

        $validated = $request->validate([
            'name'  => 'required|string|max:255',
            'email' => [
                'required',
                'string',
                'email',
                'max:255',
                Rule::unique('users', 'email')->ignore($user->id),
            ],
            'no_hp' => 'required|string|max:20',
        ], [
            'name.required'  => 'Nama lengkap wajib diisi.',
            'email.required' => 'Alamat email wajib diisi.',
            'email.email'    => 'Format alamat email tidak valid.',
            'email.unique'   => 'Email ini sudah dipakai akun lain.',
            'no_hp.required' => 'Nomor HP wajib diisi.',
        ]);

        $user->update([
            'name'  => $validated['name'],
            'email' => $validated['email'],
            'no_hp' => $validated['no_hp'],
        ]);

        return response()->json([
            'success' => true,
            'message' => 'Data profil berhasil diperbarui.',
            'user'    => $user->fresh(),
        ], 200);
    }

    // 2. Ganti Kata Sandi dengan Verifikasi Kata Sandi Lama
    public function updatePassword(Request $request)
    {
        $user = $request->user();

        $validated = $request->validate([
            'current_password' => 'required|string',
            'password'         => 'required|string|min:6|confirmed',
        ], [
            'current_password.required' => 'Kata sandi saat ini wajib diisi.',
            'password.required'         => 'Kata sandi baru wajib diisi.',
            'password.min'              => 'Kata sandi baru minimal 6 karakter.',
            'password.confirmed'        => 'Konfirmasi kata sandi baru tidak cocok.',
        ]);

        if (! Hash::check($validated['current_password'], $user->password)) {
            return response()->json([
                'success' => false,
                'message' => 'Kata sandi saat ini yang Anda masukkan salah.',
            ], 422);
        }

        // Cast 'hashed' di Model User otomatis mengenkripsi password baru
        $user->update([
            'password' => $validated['password'],
        ]);

        return response()->json([
            'success' => true,
            'message' => 'Kata sandi berhasil diperbarui.',
        ], 200);
    }

    // 3. Upload & Konversi Foto Profil (Validasi MIME ketat & Maksimal 5 MB)
    public function updatePhoto(Request $request)
    {
        $request->validate([
            'foto' => [
                'required',
                'file',
                'image',
                'mimes:jpg,jpeg,png,webp',
                'mimetypes:image/jpeg,image/png,image/webp',
                'max:5120', // 5120 KB = 5 MB
            ],
        ], [
            'foto.required'  => 'Silakan pilih foto profil terlebih dahulu.',
            'foto.image'     => 'File yang diunggah harus berupa gambar.',
            'foto.mimes'     => 'Ekstensi gambar hanya mendukung JPG, JPEG, PNG, atau WebP.',
            'foto.mimetypes' => 'Tipe MIME file tidak diizinkan oleh server.',
            'foto.max'       => 'Ukuran foto maksimal adalah 5 MB.',
        ]);

        $user = $request->user();

        try {
            $relativePath = $this->photoService->storeAndOptimize(
                $request->file('foto'),
                $user
            );

            $user->update([
                'foto' => $relativePath,
            ]);

            return response()->json([
                'success'  => true,
                'message'  => 'Foto profil berhasil diunggah dan dioptimasi.',
                'user'     => $user->fresh(),
                'foto_url' => $request->getSchemeAndHttpHost() . '/storage/' . $relativePath,
            ], 200);
        } catch (Throwable $e) {
            return response()->json([
                'success' => false,
                'message' => $e->getMessage() ?: 'Gagal memproses foto profil.',
            ], 422);
        }
    }
}

Langkah 4: Mendaftarkan 3 Rute Baru di routes/api.php

Buka berkas routes/api.php yang sudah ada sejak Modul 11, lalu tambahkan rute PUT /profile, PUT /profile/password, dan POST /profile/photo di dalam grup auth:sanctum: 

<?php

use App\Http\Controllers\Api\AuthController;
use App\Http\Controllers\Api\ProfileController;
use Illuminate\Http\Request;
use Illuminate\Support\Facades\Route;

Route::post('/register', [AuthController::class, 'register']);
Route::post('/login', [AuthController::class, 'login']);

Route::middleware('auth:sanctum')->group(function () {
    Route::get('/profile', [AuthController::class, 'profile']);
    Route::put('/profile', [ProfileController::class, 'updateProfile']);
    Route::put('/profile/password', [ProfileController::class, 'updatePassword']);
    Route::post('/profile/photo', [ProfileController::class, 'updatePhoto']);
    Route::post('/logout', [AuthController::class, 'logout']);
});
Mengapa Upload Foto Memakai POST (Bukan PUT)?
Pada mesin PHP, payload multipart/form-data (unggahan file) secara bawaan hanya diproses ke variabel $_FILES ketika metode HTTP-nya adalah POST. Oleh sebab itu, endpoint POST /api/profile/photo adalah praktik paling bersih dan bebas bug untuk upload file di Laravel.

export const API_ENDPOINTS = {
  LOGIN: `${API_BASE_URL}/login`,
  REGISTER: `${API_BASE_URL}/register`,
  PROFILE: `${API_BASE_URL}/profile`,
  UPDATE_PROFILE: `${API_BASE_URL}/profile`,
  UPDATE_PASSWORD: `${API_BASE_URL}/profile/password`,
  UPDATE_PHOTO: `${API_BASE_URL}/profile/photo`,
  LOGOUT: `${API_BASE_URL}/logout`,
};

export function getStorageImageUrl(path?: string | null): string | null {
  if (!path) return null;
  if (path.startsWith("http://") || path.startsWith("https://")) {
    return path;
  }
  return `${API_ORIGIN}/storage/${path.replace(/^\/+/, "")}`;
}

// 8. Upload Foto Profil (FormData Multipart — Mendukung HP & Expo Web)
export async function uploadProfilePhotoApi(
  token: string,
  asset: PhotoUploadAsset,
): Promise<ProfileResponse> {
  try {
    const formData = new FormData();
    const fallbackExt =
      asset.mimeType === "image/png"
        ? "png"
        : asset.mimeType === "image/webp"
          ? "webp"
          : "jpg";
    const fileName = asset.fileName || `profile_${Date.now()}.${fallbackExt}`;
    const mimeType = asset.mimeType || "image/jpeg";

    if (Platform.OS === "web") {
      const blobResponse = await fetch(asset.uri);
      const blob = await blobResponse.blob();
      formData.append("foto", blob, fileName);
    } else {
      formData.append("foto", {
        uri: asset.uri,
        name: fileName,
        type: mimeType,
      } as unknown as Blob);
    }

    // PENTING: Jangan menuliskan header "Content-Type" manual saat mengirim FormData,
    // karena fetch() akan otomatis membuat boundary multipart yang benar!
    const response = await fetch(API_ENDPOINTS.UPDATE_PHOTO, {
      method: "POST",
      headers: {
        Accept: "application/json",
        Authorization: `Bearer ${token}`,
      },
      body: formData,
    });

    return await handleApiResponse<ProfileResponse>(response);
  } catch (error) {
    if (error instanceof TypeError) {
      throw new Error(
        "Gagal mengunggah foto ke server. Pastikan server menyala (--host=0.0.0.0).",
      );
    }
    throw error;
  }
}

E. Panduan Mengatasi Error Unsupported FormDataPart implementation (Expo SDK 58+)

Gambar E.1: Pesan error pada HP saat upload foto memakai format objek { uri, name, type } lama.

Mengapa Error Seperti Gambar di Samping Bisa Muncul?

Pada Expo SDK 58 ke atas, fungsi fetch() global menggunakan mesin expo/fetch (standar WinterCG Web API). Mesin ini hanya menerima string, Blob, atau objek File dari expo-file-system di dalam FormData.

Cara React Native versi lama yang memasukkan objek { uri, name, type } ke formData.append() sudah tidak lagi didukung, sehingga muncul peringatan "Upload Foto Gagal: Unsupported FormDataPart implementation".

Untuk mengatasinya, cukup ubah cara pembacaan file pada fungsi uploadProfilePhotoApi di file src/services/authService.ts menggunakan 3 langkah berikut.

Panduan Warna Perubahan Perbaikan: + Hijau = Baris baru yang ditambahkan - Merah = Baris lama yang wajib dihapus

    const formData = new FormData();
    const fallbackExt =
      asset.mimeType === "image/png"
        ? "png"
        : asset.mimeType === "image/webp"
          ? "webp"
          : "jpg";
    const fileName = asset.fileName || `profile_${Date.now()}.${fallbackExt}`;
    const mimeType = asset.mimeType || "image/jpeg";

    if (Platform.OS === "web") {
      const blobResponse = await fetch(asset.uri);
      const blob = await blobResponse.blob();
      formData.append("foto", blob, fileName);
    } else {
      formData.append("foto", {
        uri: asset.uri,
        name: fileName,
        type: mimeType,
      } as unknown as Blob);
      const file = new File(asset.uri);
      formData.append("foto", file);
    }

    const response = await fetch(API_ENDPOINTS.UPDATE_PHOTO, {
      method: "POST",
      headers: {
        Accept: "application/json",
        Authorization: `Bearer ${token}`,
      },
      body: formData,
    });

    return await handleApiResponse<ProfileResponse>(response);
Perhatian Agar Tidak Terjadi Garis Merah pada Platform:
• Pastikan hanya ada satu blok if (Platform.OS === "web") { ... } else { ... }. Jangan menempelkan if (Platform.OS === "web") lagi di dalam blok else, karena TypeScript akan menandai error TS2367 (di dalam else, nilai Platform.OS sudah pasti bukan "web").
• Hapus juga baris const mimeType = ... karena new File(asset.uri) dari expo-file-system sudah otomatis membaca nama file, tipe MIME, dan isi biner gambar langsung dari cache HP, sehingga hasil npx expo lint tetap bersih (0 warning).
Hasil Akhir Setelah Perbaikan:
Simpan file src/services/authService.ts, jalankan ulang npx tsc --noEmit dan npx expo lint, lalu coba kembali tombol Kamera maupun Galeri di tab Profil. Foto akan langsung terunggah ke Laravel 13, tervalidasi MIME & batas 5 MB, otomatis dikonversi menjadi .webp ringan, dan langsung tampil pada lingkaran avatar!
